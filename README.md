# 🌿 台股「整張 vs 零股」盤中價差 & 掛賣監控（tw-odd-lot-spread-monitor）

一個**零第三方套件依賴**、開箱即用的台股（上市 TWSE / 上櫃 TPEx）盤中**整張與零股價差**及**零股掛賣五檔（張數／股數）**本機即時監控工具。

採用**護眼明亮豆沙米白介面**，免申請 API Key、免開戶，透過本機輕量 Python 伺服器轉接證交所免費公開行情介面，在瀏覽器按 `F5` 或點擊刷新即可查看當下整零價差與零股掛賣深度。

---

## ✨ 主要功能

- **盤中即時整零價差比對**：同時抓取證交所／櫃買中心 `mis.twse.com.tw` 整股（`getStockInfo.jsp`）與盤中零股（`getOddInfo.jsp`）即時報價，自動計算 `(零股價 − 整張價) ÷ 整張價 × 100%`。
- **零股掛賣價與張數（五檔）**：直接顯示零股**賣一價與折合張數**（1 張 = 1,000 股）、**五檔掛賣合計張數／股數**，可一鍵展開賣一～賣五完整掛賣階梯。
- **單股即時快查**：輸入任意上市／上櫃代號（系統自動辨識市場別），即可單獨查詢與刷新，並可一鍵加入常駐。
- **常駐自選股清單（自動記憶）**：自選清單與警示門檻儲存於瀏覽器 `localStorage`，支援多檔一次新增、依價差絕對值自動由大到小排序、超標高亮警示，以及可選的自動定時刷新（手動 / 10 / 30 / 60 秒）。
- **盤後自動備援**：非盤中時段（或 MIS 維護無法連線時），自動切換至 TWSE / TPEx 官方盤後收盤與盤後零股資料，晚上與假日也能測試介面。
- **護眼明亮排版**：柔和米白豆沙底色與高對比深灰文字，久看不刺眼。
- **零安裝依賴**：僅使用 Python 3 內建標準函式庫，不需要 `pip install`。

## 🚀 快速開始

### 環境需求
- **Python 3.8+**（Windows / macOS / Linux 皆可，不需額外安裝任何套件）
- 現代瀏覽器（Chrome / Edge / Safari / Firefox）

### ☁️ 雲端免費部署（Vercel — 手機 / PC 免安裝直接開網址）
本專案已內建 Vercel Python Serverless 設定（`api/quote.py` 與 `vercel.json`）：
1. 前往 [https://vercel.com](https://vercel.com) 使用 GitHub 帳號登入（個人版免費、免綁信用卡）。
2. 點選 **Add New... → Project**，匯入 `tw-odd-lot-spread-monitor`。
3. 保持預設設定，直接點 **Deploy**，約 1 分鐘即可取得專屬網址，手機可點「加入主畫面」當 App 使用。

### Windows 一鍵啟動（本機版）
1. 下載或 Clone 本專案。
2. 直接雙擊 **`啟動盤中零股價差監控.bat`**。
3. 瀏覽器會自動開啟 `http://127.0.0.1:8765`。

### macOS / Linux / 命令列啟動
```bash
python3 server.py
```
啟動後以瀏覽器開啟：`http://127.0.0.1:8765`

> 詳細操作流程與盤中實戰注意事項，請參閱 **[SOP.md](./SOP.md)**。

## ⚙️ 資料來源與注意事項

1. **免費官方來源**：
   - 盤中即時：`https://mis.twse.com.tw/stock/api/getStockInfo.jsp`（整股）、`getOddInfo.jsp`（盤中零股）
   - 盤後備援：TWSE `MI_INDEX`、`TWT53U` 與 TPEx OpenAPI（`tpex_mainboard_daily_close_quotes`、`tpex_odd_stock`）
2. **查詢頻率限制**：證交所免費網頁介面設有單一 IP 防爬蟲限流，建議以**手動刷新（F5）**為主，或將自動刷新間隔設為 **10～30 秒以上**，避免過於頻繁請求導致暫時被擋。
3. **揭露範圍**：盤中零股公開行情最多揭露**最佳五檔**掛單（賣一～賣五）。
